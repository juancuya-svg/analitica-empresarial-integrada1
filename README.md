## 🧠 ¿Qué es Analítica Empresarial Integrada?

Este curso busca desarrollar la capacidad de **transformar datos en decisiones empresariales con sustento**, integrando análisis, interpretación, modelos y herramientas tecnológicas en contextos reales de negocio.

No se trata únicamente de obtener resultados técnicos, sino también de:
- interpretar hallazgos,
- reconocer riesgos,
- comunicar resultados,
- y evaluar alternativas de decisión.

📈 La escalera analítica

El curso desarrolla cuatro niveles de analítica, cada uno con una finalidad distinta:

Nivel	Pregunta clave	Finalidad
📊 Descriptiva	¿Qué pasó?	Entender los resultados observados
🔎 Diagnóstica	¿Por qué pasó?	Explicar factores asociados al cambio
🔮 Predictiva	¿Qué podría pasar?	Anticipar escenarios futuros
⚙️ Prescriptiva	¿Qué conviene hacer?	Evaluar alternativas y apoyar decisiones

🧩 Forma de trabajo

Los notebooks y entregables desarrollados en este curso buscan mantener cuatro principios fundamentales:

01 · Reproducibilidad

El análisis debe poder revisarse y replicarse a partir del código y los datos empleados.

02 · Interpretación

Los resultados deben explicarse en términos comprensibles dentro del contexto empresarial.

03 · Evidencia

Las conclusiones deben estar sustentadas por métricas, visualizaciones y resultados verificables.

04 · Decisión

Cada análisis debe responder a una pregunta de negocio y aportar elementos útiles para evaluar alternativas.

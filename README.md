## 💡 ¿Qué es Analítica Empresarial Integrada?

La **Analítica Empresarial Integrada** permite utilizar datos, métricas, modelos y herramientas tecnológicas para comprender problemas empresariales y generar información que apoye la toma de decisiones.

Durante el curso se trabaja no solo en la parte técnica del análisis, sino también en la **interpretación de resultados, evaluación de riesgos, comunicación de hallazgos y análisis de alternativas**.

## 📈 La escalera analítica

El análisis de datos puede desarrollarse en distintos niveles dependiendo de la pregunta que se busca responder.

| Nivel | Pregunta | Propósito |
|---|---|---|
| 📊 **Descriptiva** | ¿Qué pasó? | Comprender los resultados observados |
| 🔍 **Diagnóstica** | ¿Por qué pasó? | Identificar factores relacionados con el cambio |
| 🔮 **Predictiva** | ¿Qué podría pasar? | Anticipar escenarios futuros |
| ⚙️ **Prescriptiva** | ¿Qué conviene hacer? | Evaluar alternativas y apoyar decisiones |

> **Describir → Explicar → Anticipar → Decidir**

# 🧩 Forma de trabajo

Los notebooks y entregables desarrollados durante el curso buscan mantener cuatro principios fundamentales:

### 01 · Reproducibilidad

El análisis debe poder revisarse y reproducirse mediante el código, los datos y los procedimientos utilizados.

### 02 · Interpretación

Los resultados deben explicarse de manera clara y relacionarse con el contexto empresarial.

### 03 · Evidencia

Las conclusiones deben estar respaldadas por métricas, visualizaciones y resultados verificables.

### 04 · Decisión

El análisis debe responder a una pregunta empresarial y aportar elementos útiles para evaluar diferentes alternativas.
